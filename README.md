# 1SB-LSD／1Bz-LSDの構造・電子状態と反応小モデルの計算研究

文章更新：2026年10月25日。収録した計算記録は2026年8月26日まで。

1SB-LSDのpara-トリメチルシリル（TMS）基が、N1アシル基周辺への接近しやすさと電子状態に与える影響を、非TMS対照の1Bz-LSDと比較した計算研究です。研究発表の補足として、仮説、計算条件、結果、未解決点、参考文献をまとめています。

調べた自由分子の静的モデルでは、TMSによる反応中心の大きな直接遮蔽差は検出されず、小さな電子状態差が得られました。別の検討では、OH⁻が関わる非酵素的な反応を仮定し、Bz小モデルで四面体中間体からC–N結合が切れる遷移状態候補とIRC接続を確認しました。**1SB-LSDの生体内代謝速度や主要代謝経路は、この研究から確定していません。** 1Bz-LSDはpara-TMS置換の対照であり、1SB-LSDの実証済み代謝中間体とは扱いません。

## 公開データの範囲と来歴

`research_results/` は既存の軽量保存データです。主に2026年8月23日までの成果を収録し、原本との対応と当時のハッシュを [SNAPSHOT_MANIFEST.json](research_results/SNAPSHOT_MANIFEST.json) に記録しています。フォルダの目次は公開版に合わせて更新しました。初回公開時の文献整理1件の修正と、今回のMarkdownの日本語化・推敲は[PUBLIC_DOCUMENT_EDITS.json](PUBLIC_DOCUMENT_EDITS.json)に変更前後のハッシュを記録しています。計算数値は変更していません。

`h11_evidence/` と `supplementary/` は、その保存データを補う選択資料です。数値・計算条件を保持し、ローカルの絶対パスの接頭部分を `${WORKSPACE}` などに置換しています。複製元と公開ファイルのSHA-256は各フォルダのmanifestに記録しています。

約5 GiBの完全計算原本、全試行、再開用波動関数、実行用ソース一式は、この公開用パッケージには含まれません。したがって、収録データの検討・監査はできますが、**パッケージ単独で研究全体を完全再実行できる構成ではありません**。第三者製の実行ファイル、個人の会話記録、未完成草案も収録していません。

全公開ファイルのハッシュは [PACKAGE_FILES_SHA256.txt](PACKAGE_FILES_SHA256.txt) にあります。このリポジトリの `.gitattributes` は、Gitによる改行変換で検証用ハッシュが変わらないように設定しています。再利用ライセンスは設定していません。
